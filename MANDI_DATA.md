# FarmSense Mandi Price Data

FarmSense has two market-price paths:

1. optional live data.gov.in / AGMARKNET lookup
2. a local generated monthly archive for demos and offline analysis

## Live price path

When `DATA_GOV_API_KEY` is configured on the backend, FarmSense queries the data.gov.in AGMARKNET resource for supported commodity mappings.

The frontend never needs this key.

## Important provenance note

The current committed archive is **generated by the project archive builder** from project market baselines with deterministic trend, seasonal and volatility logic.

The current summary file records:

```text
official_api_seeded_crops: 0
```

Therefore these 7,000 rows should not be described in academic work as 7,000 directly observed historical AGMARKNET records.

If a paper requires official historical observations, use a separately sourced historical dataset and document provenance.

## Rebuild

```bash
cd backend
python build_mandi_price_archive.py
```

With a valid backend `DATA_GOV_API_KEY`, current official modal prices may be used as seed values where a commodity match exists.

## API endpoints

```text
GET /market-prices
GET /market-prices?crop=tomato&state=Karnataka&district=Bengaluru%20Urban
GET /market-history
GET /market-history?crop=tomato&limit=24
```

## Backend environment variable

```text
DATA_GOV_API_KEY=your_data_gov_api_key
```

Keep the key only on the backend.
